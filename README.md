# Pizza Survivor 🍕

A minigame called "Pizza Survivor" made for the Udemy course "Python TOTAL con IA".
The project was developed using Visual Studio Code and GitHub Copilot as a coding assistant.

## Description

Pizza Survivor is a Python minigame where the player must survive as long as possible while avoiding enemies and increasing their score.

## Features

- Player movement
- Enemy spawning
- Score tracking
- Survival gameplay

## Tools

- VS Code
- GitHub Copilot
- GitHub Desktop
- Git & Github

## Technologies

- Pygame
